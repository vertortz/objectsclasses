# Задания по классам и ООП

Сделал вместе с Кодебай Адиятом
Учебный проект на Java: все 30 заданий собраны в отдельных классах, а `Main`
последовательно демонстрирует их работу. Пересекающиеся задания переиспользуют
одни и те же классы `Student`, `Car` и `BankAccount`.

## Требования

- JDK 21 или новее

## Компиляция и запуск

Из корневой папки проекта в PowerShell:

```powershell
New-Item -ItemType Directory -Force out
javac -d out src\*.java
java -cp out Main
```

Для самостоятельного запуска каждого задания измените примеры в `src\Main.java`.
